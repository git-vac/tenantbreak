# Changelog

## 0.4.0

- Check known protected records within paginated collections with explicit identification, row isolation and bounded coverage.
- Confirm explicitly configured partial-field exposure while retaining complete owner controls.
- Add a separate, opt-in disposable write runner for create/update/delete effects with independent state observations, owner positive controls and verified reset.
- Stop later writes after unverified cleanup or ambiguous mutation timeouts/interruption; retain observed findings and incomplete outcomes.
- Extend offline HTML/JSON/JUnit evidence and comparisons for collection coverage, state changes and cleanup.
- Include executable collection and write policies, vulnerable/fixed HTTP experiments and regression tests.

## 0.3.0

- Configure custom authentication headers or session cookies per identity, retaining bearer-policy compatibility and account verification.
- Refresh bearer credentials explicitly before a run through a bounded, same-origin OAuth refresh-token grant with basic/body/public client support.
- Save rotated credentials to new private files and reuse them without putting values in policies, command arguments or evidence reports.
- Keep credentials fixed during probes; authentication failures are not retried or reduced to passing denials.
- Add header, cookie and rotating-token lab modes, policy examples and HTTP integration tests.
- Replace the demo overview and comparison headlines with direct descriptions.

## 0.2.0

- Select probes by identity, resource or case while retaining required identity verification and owner controls.
- Replay recorded findings with a matching policy, fresh environment credentials and an explicitly configured target.
- Compare saved evidence offline with strict scope/definition checks, readable HTML and CI results for new, persistent and resolved leaks.
- Validate saved report structures and recompute evidence outcomes before replay/comparison; add explicit scope and case fingerprints in report schema 2.
- Create editable policy drafts and extract GET routes from local OpenAPI 3.0, 3.1 and 3.2 JSON/YAML documents.
- Finalize completed drafts into runnable policies without making API requests or copying credential examples.

## 0.1.0
